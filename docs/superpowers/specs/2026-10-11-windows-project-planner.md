# 개인용 Windows 프로젝트 플래너 설계 초안

Source: https://chatgpt.com/space/page_216f8f83c2308191be7b6eaa31b0c246

Approved by user: 2026-10-11. This is the approved source snapshot; implementation status is tracked separately.

한 사람이 여러 Windows PC에서 진행 중인 프로젝트와 일정을 관리하는 설치형 앱의 검토용 설계입니다. 프로젝트 목록에서 항목을 선택하면 작업 표와 시간축 간트 차트가 열립니다. 온라인 상태에서만 편집하며, 같은 개인 계정의 데이터가 PC 간 동기화됩니다.

프로젝트 우선 화면, 시간축 차트, 막대 드래그, Windows 설치형, 개인용 다중 PC 동기화, 온라인 전용 편집은 확인된 요구사항입니다. 아래 계산·복구·검증 방식은 이번 문서에서 검토할 세부 설계입니다.

## 첫 버전 범위

프로젝트 생성·수정·보관, 작업 표와 간트 차트, 날짜·진행률 편집, 막대 이동과 기간 조절, 자동 저장, 동기화 상태와 충돌 안내를 제공합니다. 공동 작업자, 작업 의존관계, 첨부파일, 알림, 오프라인 편집은 첫 버전에서 제외합니다.

## 프로젝트 목록

첫 화면에 진행 중인 프로젝트의 이름·진행률·마감일을 표시합니다. 이름 검색과 마감일순·최근 수정순 정렬을 제공하고, 보관 목록과 휴지통은 분리합니다. 프로젝트 이름은 필수이며 마감일이 없으면 ‘미정’으로 표시합니다. 새 프로젝트 생성 후 상세 화면으로 이동합니다.

프로젝트 진행률은 삭제되지 않은 작업을 동일한 비중으로 평균한 값입니다. 작업이 없거나 진행률 미입력 작업이 하나라도 있으면 전체 값은 ‘미산정’으로 표시하고 입력 완료 작업 수를 함께 보여줍니다. 미입력을 0%로 계산하지 않습니다. 계산값은 작업량이나 연구 성과의 독립적 검증을 뜻하지 않습니다.

## 작업 표와 간트 차트

왼쪽 표에 작업명·시작일·종료일·진행률을, 오른쪽 같은 행에 간트 막대를 표시합니다. 세로 스크롤과 선택 상태를 연동하고 열 너비와 좌우 비율을 조절할 수 있습니다. 작업 추가·수정·삭제·순서 변경, 날짜 선택기, 일·주 시간축, 오늘 및 프로젝트 마감일 표시선을 제공합니다.

막대 전체를 끌면 기간을 유지하며 시작일과 종료일이 이동합니다. 끝부분을 끌면 해당 날짜만 변경됩니다. 하루 단위로 이동하고 드래그 중 예상 날짜를 표시합니다. 놓으면 저장을 요청하고 Esc로 취소합니다. 표 입력으로도 동일한 변경을 할 수 있습니다.

## 날짜와 진행률 규칙

일정은 시간대 없는 달력 날짜로 저장합니다. 시작일과 종료일을 모두 포함하며 같은 날 작업은 1일입니다. 주말과 공휴일을 포함합니다. 오늘 표시 기준은 앱 기본 설정인 한국시간으로 통일합니다. 서버의 생성·수정 기록은 UTC 시각으로 저장하고 표시 시 변환합니다.

작업 날짜는 둘 다 비우거나 둘 다 지정합니다. 날짜가 없으면 표에 ‘일정 미정’으로 표시하고 막대는 그리지 않습니다. 종료일이 시작일보다 빠르면 저장할 수 없습니다.

작업 진행률은 미입력 또는 0~100의 정수입니다. 0%는 시작 전, 100%는 완료로 표시하며 날짜가 지나도 자동 변경하지 않습니다. 프로젝트 마감일을 넘는 작업은 경고하되 저장은 허용합니다. 프로젝트 마감일 변경은 작업 날짜를 자동 이동시키지 않습니다.

## 인증과 동기화 구조

Windows 앱, 사용자 인증, 중앙 저장 서비스로 구성합니다. 화면·일정 계산·저장 통신을 분리합니다. 서버는 모든 조회·변경에서 소유자를 검사하며 다른 사용자의 식별자를 알아도 접근할 수 없어야 합니다. 앱에 관리자용 비밀키를 포함하지 않습니다.

입력 확정 또는 드래그 종료 시 자동 저장하고 ‘저장 중·저장됨·저장 실패’를 구분합니다. 서버 확인 전에는 저장 완료로 표시하지 않습니다. 저장 중 해당 프로젝트의 추가 변경을 잠시 잠가 순서를 보장합니다.

앱 활성화·재연결 시 새로 조회하며, 활성 화면에서는 최대 10초 간격으로 변경을 확인하는 방식을 기본 설계로 합니다. 동기화 실패 시 최신 상태임을 표시하지 않습니다.

## 충돌과 연결 끊김

프로젝트 버전 번호는 작업 변경에도 증가합니다. 모든 변경은 읽었던 버전과 함께 제출하고 서버가 버전 확인과 저장을 원자적으로 수행합니다. 다른 PC가 먼저 변경했다면 덮어쓰지 않고 서버 최신 값과 내 변경안을 보여줍니다. ‘최신 내용 사용’ 또는 ‘내 변경안을 다시 적용’을 선택하며 다시 적용할 때도 버전을 검사합니다. 서버에서 삭제된 항목은 묵시적으로 되살리지 않습니다.

연결 끊김 또는 로그인 만료 시 편집을 잠그고 마지막 확인 시각을 표시합니다. 이미 입력한 미저장 변경안은 Windows 사용자별 보호 저장소에 보존하며 재시작 후 복구합니다. 연결 전에는 추가 편집이나 서버 반영을 하지 않습니다. 로그아웃 시 미저장 변경 보존·폐기 여부를 확인하고 계정 간 노출을 막습니다.

저장 요청마다 고유 식별자를 붙입니다. 응답만 유실된 경우 재연결 후 서버의 처리 여부를 확인하고 미반영 요청만 충돌 검사 후 재시도합니다. 중복 생성이나 중복 적용을 방지합니다.

## 데이터와 복구

프로젝트: 식별자, 소유자, 이름, 선택적 마감일, 버전, 생성·수정 시각, 보관·삭제 시각.

작업: 식별자, 프로젝트 식별자, 이름, 선택적 시작일·종료일, 선택적 진행률, 순서, 생성·수정·삭제 시각. 접근 권한은 프로젝트를 따릅니다.

변경 요청 기록: 요청 식별자, 소유자, 대상 프로젝트, 기준 버전, 처리 결과. 서버와 앱 모두 같은 요청의 재처리 결과를 일관되게 판단할 수 있어야 합니다.

보관한 프로젝트는 읽기 전용이고 보관 해제 후 편집할 수 있습니다. 삭제 전 대상과 영향받는 작업 수를 확인합니다. 삭제 항목은 휴지통에서 복원하며 첫 버전에는 자동 영구 삭제나 휴지통 비우기를 제공하지 않습니다. 프로젝트 복원은 함께 삭제된 작업만 복원하고 이전에 개별 삭제된 작업은 유지합니다.

## 화면 스타일

연한 청회색 배경, 흰 카드, 블루 강조색을 사용합니다. 간격과 정렬이 정밀한 도면처럼 느껴지되 장식보다 일정 읽기와 편집을 우선합니다. 선택·오류·저장 상태를 색상뿐 아니라 문구와 아이콘으로 구분하고 키보드 이동·포커스 표시·Windows 화면 배율 변경을 지원합니다.

## 검증과 완료 기준

- 프로젝트·작업의 생성, 수정, 보관, 삭제, 복원 검증

- 표 입력과 막대 이동·기간 변경 결과 일치, Esc 취소 확인

- 1일 작업, 월말, 윤년, 미정 날짜, 미입력 진행률 검증

- 두 PC 동시 수정에서 조용한 덮어쓰기 없이 충돌 안내

- 요청 전·중·후 연결 끊김, 응답 유실, 재시작 후 미저장 변경 복구

- 계정 만료·전환 처리와 다른 계정 데이터 접근 차단

- Windows 11 x64에서 설치, 실행, 업데이트, 제거 검증

- 업데이트 후 데이터 유지와 앱 제거 시 서버 데이터 보존 확인

첫 검증 대상은 Windows 11 x64로 제안합니다. 실제 Windows 검증 전에는 설치 프로그램이 검증되었다고 표시하지 않습니다. 다른 Windows 버전·ARM 지원은 별도 검증 범위입니다.

## 개발과 배포의 결정 경계

개발은 사용자가 지정한 Codex 클라우드 환경에서 진행합니다. 2026년 10월 11일 확인 시 저장된 클라우드 개발 환경이 없어 환경 설정이 필요합니다. 이 문서는 검토용 Page이며 아직 개발 저장소에 파일로 저장하거나 커밋하지 않았습니다.

기술 스택, 인증·저장 제공업체, 운영비, 설치 프로그램 서명과 배포 방식은 구현 계획에서 비교해 결정합니다. 설계 검토 승인은 계정 생성, 비용 지출, 인증 권한 부여 또는 외부 공개 배포의 승인을 포함하지 않습니다.

다음 단계는 이 설계의 검토와 승인입니다. 이후 구현 계획을 작성하고 검토한 뒤 실제 개발을 시작합니다.
